# Security Policy

## Supported Versions

Security updates are actively provided for the latest releases of `ansv-haptics-sim`.

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2.0 | :x:                |

---

## Reporting a Vulnerability

We take the security of `ansv-haptics-sim` seriously. If you discover a security vulnerability, please report it responsibly rather than opening a public issue.

### How to Report
1. Email your report privately to `support@ansv.net`.
2. Include details of the potential vulnerability, steps to reproduce, and any impact assessment.

### Response & Handling Timeline
* **Acknowledgement**: Within 48 hours of receipt.
* **Assessment & Fix**: We will work to verify and release a security patch as quickly as possible.
* **Public Disclosure**: A public security advisory will be published once a fix is released.

Thank you for helping keep `ansv-haptics-sim` secure!
